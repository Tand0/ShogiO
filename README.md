# ShogiO

- これは Android アプリケーションのソースコードです。
- これはCSAプロトコルを使用して動作する将棋クライアントです。

## プライバシーポリシー

- [プライバシーポリシー](praivacy.md)
- [イシューを書く場所](https://github.com/Tand0/ShogiO/issues)

- 定跡ファイル [./app/src/main/assets/mytable_small.zip](./app/src/main/assets/mytable_small.zip) は大きすぎて入りませんでした。
    - 必要であれば自分で生成してください。

- 実行アプリについては [tandd0.shogio](https://play.google.com/store/apps/details?id=com.github.tand0.shogio) を参照してください。
